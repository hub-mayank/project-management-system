# Code of Conduct

## Our pledge

We want this project to be a friendly place to learn and build together, whatever your experience level.

## What we expect

- Be respectful and patient, especially with people who are new to Git or open source
- Give feedback on the code, not the person
- Accept review comments openly, they are there to improve the change
- Ask questions in issues and pull requests so others can learn from the answers

## What is not acceptable

- Insults, harassment or discrimination of any kind
- Personal attacks or trolling
- Sharing other people's private information
- Pushing someone else's work as your own

## Enforcement

The maintainer can edit or remove comments, issues and pull requests that do not follow this code, and can block repeat offenders. If you see a problem, open an issue or contact the maintainer, [@hub-mayank](https://github.com/hub-mayank).
